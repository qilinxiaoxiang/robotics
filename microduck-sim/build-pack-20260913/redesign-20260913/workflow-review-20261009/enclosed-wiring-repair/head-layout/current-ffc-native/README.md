# Current camera cable work

The Pi and camera endpoints are held at the current native head positions. This directory contains local connector-exit examples, not an accepted complete 200 mm route. The actual received SC1892 Rev2 has an 11.5 mm narrow majority and a wider standard connector end; the camera example conservatively retained the earlier 16 mm terminal region as an explicitly assumed receiving shape.

The Pi-side R1.5 return is clear of the 90 listed current local rigid objects. Its 0.3 mm thickness and 0.5 mm external straight are example dimensions, not manufacturer bend or reinforced-tab limits. Keep the connector straight as supplied and arrange the soft section gently; do not force the depicted bend.

The first camera-side example contacts the existing face, camera and one roof rib, so it is retained only as a failed route example. No printed-part change follows from this restricted curve.

The OpenRB remains a head-layout requirement. Middle cable storage is deliberately not frozen until that board, its rigid plugs and adjacent lines have a common position. No source print geometry was changed.
