# V1 黑色七件原生读回

七件是眼圈、三螺钉相机压框、GitHub 原版 community-24 支架、四片 1 mm M2 垫片。`Black_V1_native.3mf` 是 Orca CLI 原生切片证据；`Black_V1_candidate.gcode` 是其中的原始刀路副本。当前没有原生 GUI 缩略图，**不标为机器就绪文件**。

验收记录：`native-audit.json` 与 `functional-readback.json`。七件源三角拓扑和变换后顶点完全对应；原支架只平移，原打印朝向未变。模型层数：眼圈47、压框12、支架94、垫片每片5。实际刀路件间最小间距下界14.925 mm，床边48.369 mm。所有七件首层有实际模型挤出。

以实际源网格逐层截取闭合小孔，检查96个孔截面与原生线宽、圆弧刀路的间距。压框24处孔层、垫片20处孔层均无支撑侵入核心或超过0.35 mm的孔径损失。四垫片通孔最小保守直径2.18337 mm。

本检查覆盖小竖孔和首层，不把支架横轴承座的支撑可拆性、相机整机可装入性或真实印件配合宣称通过。压框和原支架首层确有支撑，具体面积见报告。主线程继续整合完整V1包；本目录不独立发布。
