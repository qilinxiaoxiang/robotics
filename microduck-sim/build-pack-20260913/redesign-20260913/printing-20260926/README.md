# MicroDuck: six sliced plates

**Revised 2026-09-26:** Plate 1 now contains the restored third head-cap mounting boss. All six files below were regenerated and verified against the corrected source. The withdrawn first version is preserved only under `superseded-before-fastener-review/`.

The `SD-CARD` folder contains six native Bambu Studio exports, named `zhengxia_microduck_plate_1.gcode.3mf` through `zhengxia_microduck_plate_6.gcode.3mf`. Copy these six files unchanged to the microSD card; do not unzip them. Select one file on the printer for each print job.

The files contain the printing paths and settings. No additional slicing is needed when using the matching setup: Bambu Lab X1 Carbon, 0.4 mm nozzle, Cool Plate, and Bambu PLA Basic. The recipe uses 0.2 mm layers, four walls, 30% gyroid infill, automatic tree supports, 220 C nozzle temperature and 35 C bed temperature. If the actual nozzle, plate or filament profile differs, update the editable project and slice again before printing.

At the printer, confirm the installed plate and filament match, select the actual PLA spool/AMS slot if prompted, enable bed leveling, and use Standard (100%) speed. Prepare the Cool Plate according to the club guide and remain for the first few layers. File preparation does not replace the club's training requirement.
