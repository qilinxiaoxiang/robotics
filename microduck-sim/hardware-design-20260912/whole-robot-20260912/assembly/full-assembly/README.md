## 同一刚体的固定装配接触

同一刚体内的部件没有关节相对运动，因此 404 对部件只做一次静态审计，未在 250 帧里重复计算。没有将这些排除项隐藏：[完整排除清单](same-body-exclusions.json)记录每一对及其相交体积。

超过阈值的 5 对记录均已分类：

- 一体支架与原电池卡件 14.6247 mm³、与左壳 0.0292 mm³，在修改前已存在。
- 加厚的 OpenRB 空间预留与头盖支柱 24.1227 mm³、与螺丝参考件 48.9317 mm³。该预留将 PCB 孔填平，故覆盖穿板支柱和螺丝。改用未加厚、恢复四个直径 2.5 mm 安装孔的实体包络独立复核后，两对实际相交分别小于 2×10⁻¹⁵ mm³ 与 0；孔距 61.5×20.5 mm 来自 ROBOTIS 原件。见[孔位与固定接触复核](openrb-fixed-contact-confirmation.json)。
- Pi GPIO 与 Pi 板上元件的两个预留空间相交 1,185.60 mm³。它们描述同一块 Pi 的相邻区域，都是零额外质量的预留，不是两个真实实体互撞。
