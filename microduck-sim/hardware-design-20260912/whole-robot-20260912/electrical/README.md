# 整机仿真：电子件质量与原模型计重边界

核验于 2026-09-12，推进 P5。最先读 `component-mass-envelope.json`；它把厂家值、商家测量值与工程假设分开。`UART-EXPLANATION.md` 给出树莓派/OpenRB 接口的原理图和固件证据。

## 可以直接用于计算的新增信息

- 主电子件：Gens ace 2S 850 mAh 电池 57 g；Pololu D24V150F5 19 g；S13V30F5 3.5 g；Adafruit MAX98357A 页面值 1.2 g；扬声器 3 g；Camera Module 3 Wide 4 g；OpenRB 13 g；Pi Zero 2 W 商家测量值 10 g；具体选用 Adafruit BNO085 板 2.5 g。
- 这些是整套电子件的名义质量 **113.2 g**，不是对原模型直接增加 113.2 g。加上明确标为工程假设的 SD 卡、线束、保险、开关等，名义为 **153.7 g**；打印件和机械螺丝另计。
- 电池厂家质量容差实际是 **±20 g**，所以质量敏感性测试采用 37–77 g。尺寸 58×32×20 mm 的厂家容差是 ±5/±2/±2 mm，最大包体为 63×34×22 mm；两组电线和插头的安装空间另算。
- OpenRB 原理图对应的机械图显示：上部到 PCB 底面 10 mm，向下排针另有 8.85 mm，完整带排针高 **18.85 mm**。不能按 10 mm 总高检查碰撞。
- MAX98357A 页面列 3 mm/1.2 g，但同时说明当前版本带预焊端子；二者可能不包含相同配件。清单把端子空间与质量不确定性单独放进安装余量。

每件的原始网页链接、裸件尺寸、安装余量、质量区间依据都在 JSON。未找到官方重量的零件保持工程假设，不伪装成厂商公差。电池原来的网页已转向当前新地址，JSON 使用本次读到的现行厂家页。

## 原模型到底已包含哪些东西

`existing-model-mass-audit.json` 是脚本从本地文件重新提取的结果：

- 当前官方 `robot_allcollisions.xml` 的全部显式质量合计 **737.24318 g**。
- `trunk_base` 已合并 199.224 g，内有 `np_f970` 电池网格。该网格约 38.61×20.58×70.81 mm，**不能看见名字就减去市售另一款 NP-F970 的 240 g**，那甚至比这个 body 的全部质量还大。
- `jaw_soft` 是包含整组头部电子件的 body 名，合并质量 188.766 g。它包含 Pi、robot_hat、speaker、M12 镜头座和 lens。`bottom_head_shell` 是视觉零件名，不能误当这组惯性的 body 名。
- 旧社区模型质量合计 818.90954 g；其 `trunk` 为 347.283 g，电池网格约 41×76.3×20.5 mm。Pi 只有零件注释，无法据此恢复独立重量。
- `imu`/`head_imu` 是 MuJoCo 的传感器坐标点，坐标点本身不能证明某块外置 BNO085 板已经被计重。官方 HAT 的实际集成器件质量需作为 HAT 整体处理。

`assets/*.part` 全部是 Onshape 标识、零件编号与固定版本信息，不含独立质量/惯性。已尝试固定版本的官方质量属性端点，匿名请求返回 HTTP 401。原模型只留下合并惯性，所以当前没有足够信息精确拆出旧电池、旧 HAT、旧音响和旧镜头的真实质量。

## 怎样继续仿真而不制造一个假的“替换完成”结论

1. 保留原模型惯性，附加新组件，可作为明确标注的附加载荷压力测试；它通常增加负担，但重量更大不自动保证所有动力学情况都更保守，因此不能将通过结果视为替换模型的可靠证明。
2. 做替换敏感性情形时，把旧部件移除质量当成未知参数。用 JSON 里的旧部件位置与单位质量惯性进行减法；每个情形检查剩余质量、质心和惯性矩阵在物理上可成立。
3. 本次审计给出基于“网格均匀密度＋剩余非负质量分布”的单件移除上界，例如 `np_f970` 为约 123.20 g。这是数学约束，不是推算出的真实电池质量；多个零件的单件上界不能同时全部取到。
4. 更严格的整机结论仍须原 CAD 独立质量属性或真实零件称重。缺少这个数据时，结论必须写出它在哪些旧部件质量假设下成立，不能把假设隐藏在一个看起来精确的总重量里。

删除 XML 里的 visual/collision geom（显示/碰撞几何）不会改变已明确给出的 `<inertial>`。只改总质量而不更新质心和转动惯量，也不能代表正确替换。`audit_existing_mass.py` 输出旧组件坐标、四元数、均匀网格单位质量惯性及 body 原始惯性；没有修改任何原始模型。
