PAGE 6
Exporting Designs From CAD Software
After creating your model, you need to export it as an STL from your CAD 
software. When downloading from websites like Thingiverse, the files will be 
supplied as STLs
Solidworks: File → Save As → Save as type → STL
Fusion 360: File → 3D Print → Deselect ‘Send to 3D Print Utility’ → OK
On-Shape: Right Click Part → Export → Format ‘STL’ → OK

Print Setup: Printer, Filament and Build Plate
Before setting up a print, ensure that 
these settings are selected:
Printer: Bambu X1 Carbon 0.4
Plate: Cool Plate
Filament: PLA Basic
Mistakes here can lead to major print 
failures!


PAGE 13
Print Setup: Detail
Print Settings: Select the layer height for 
the printer. Larger layers will print faster 
but lose some detail. ‘0.20mm Standard’ 
is a good balance of speed and quality


PAGE 14
Print Setup: Supports
Supports: If you have overhangs at more 
than ~45-60 degrees, select ‘Enable 
Support.’ Otherwise select ‘None.’


PAGE 15
Print Setup: Infill
Infill: What percentage of the inside of 
the print is solid. For aesthetic parts or 
parts with little to no stress, 10-15% is 
good. For parts that need more strength, 
use higher infill

PAGE 17
Slicing Your Model
Once you are happy with the orientation and scale of 
your model(s) and have changed the printing settings, 
select ‘Slice plate’
This will slice up your model into a series of 
horizontal layers. You can view the total print 
time in the at the bottom of the generated table


PAGE 18
Exporting G-code
Once sliced, get an SD card from a 
printer and save the g-code to the 
SD card by pressing “Export plate 
sliced file.” Save to the printer’s 
microSD card
→ You are required to put your 
AndrewID at the start of the 
filename!!!
